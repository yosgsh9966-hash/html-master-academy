🧠 ما هي HTML؟

HTML هي اختصار لـ HyperText Markup Language أي لغة ترميز النص التشعبي.

وهي اللغة الأساسية التي نستخدمها لبناء هيكل صفحات الويب.

باستخدام HTML نستطيع إنشاء العناوين، والفقرات، والصور، والروابط، والقوائم، والأزرار، وغيرها من عناصر الصفحة.

💻 هل HTML لغة برمجة؟

لا، HTML ليست لغة برمجة بالمعنى التقليدي.

HTML هي لغة ترميز Markup Language وتستخدم لتحديد هيكل ومحتوى الصفحة.

لاحقًا ستتعلم أن:

  • 🎨 CSS مسؤولة عن الشكل والتصميم.
  • ⚙️ JavaScript مسؤولة عن التفاعل والوظائف.
  • 🏗️ HTML مسؤولة عن هيكل الصفحة ومحتواها.

🧩 كيف تعمل HTML؟

المتصفح مثل Chrome أو Edge يقرأ كود HTML ثم يحوله إلى صفحة يستطيع المستخدم رؤيتها.

مثال بسيط: 

<h1>مرحبا بالعالم</h1>

هذا الكود ينشئ عنوانًا رئيسيًا يحتوي على النص: مرحبا بالعالم.

🏷️ ما هو الـ Tag؟

الـ Tag أو الوسم هو العنصر الذي نستخدمه لإخبار المتصفح بنوع المحتوى.

مثلًا: 

<h1>عنوان رئيسي</h1>

<p>هذه فقرة نصية.</p>

<button>اضغط هنا</button>

كل وسم له وظيفة معينة.

🧱 أول صفحة HTML

الصفحة الأساسية في HTML تحتوي عادةً على مجموعة من العناصر المهمة. 

<!DOCTYPE html>

<html>

<head>
    <title>صفحتي الأولى</title>
</head>

<body>

    <h1>مرحبا بالعالم</h1>

    <p>هذه أول صفحة HTML لي.</p>

</body>

</html>

لا تقلق إذا لم تفهم كل شيء الآن. سنتعلم كل جزء بالتفصيل في الدروس القادمة.
