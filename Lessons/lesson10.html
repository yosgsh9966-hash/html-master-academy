تعلم كيفية إضافة ملفات الصوت والفيديو وتضمين المشغلات داخل صفحتك مباشرة باستخدام HTML5.

🎵 ملفات الصوت

عنصر التشغيل الصوتي <audio>

يسمح الوسم <audio> بتضمين المقاطع الصوتية (مثل صيغ MP3 أو WAV) داخل الموقع مع أزرار التحكم.

  • controls: لإظهار أزرار التشغيل، الإيقاف، وشريط الصوت.
  • autoplay: لتشغيل المقطع تلقائياً (قد تتطلب كتم الصوت للعمل في بعض المتصفحات).
  • loop: لتكرار تشغيل المقطع تلقائياً عند انتهائه.
<audio controls>
    <source src="audio.mp3" type="audio/mpeg">
    <source src="audio.ogg" type="audio/ogg">
    متصفحك لا يدعم مشغل الصوت.
</audio>
🎬 ملفات الفيديو

عنصر الفيديو <video>

يُستخدم الوسم <video> لملفات الفيديو (مثل MP4 و WebM). ويمتلك نفس خصائص الصوت بالإضافة إلى:

  • poster: صورة غلاف تعريضية تظهر قبل بدء تشغيل الفيديو.
  • muted: لكتم صوت الفيديو عند بداية التشغيل.
  • width و height: لتحديد أبعاد مشغل الفيديو.
<video controls poster="thumbnail.jpg" width="600">
    <source src="movie.mp4" type="video/mp4">
    <source src="movie.webm" type="video/webm">
    متصفحك لا يدعم تشغيل الفيديو.
</video>
