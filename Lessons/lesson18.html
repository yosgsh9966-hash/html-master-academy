تطبيقات الويب التقدمية والتخزين المحلي (PWA & Local Storage)

احترف تحويل موقعك إلى تطبيق يعمل بدون إنترنت وتعلّم تخزين بيانات المستخدمين بأمان داخل المتصفح.

تقدمك في الدورة 90%
📱 تطبيقات PWA والبيانات

ما هي تطبيقات PWA والتخزين المحلي؟

تسمح تقنيات PWA (Progressive Web Apps) لمواقع الويب بالعمل كالتطبيقات المنفصلة على الأجهزة الذكية، بينما يتيح التخزين المحلي احتفاظ المتصفح ببيانات المستخدم حتى بعد إغلاق الصفحة.

📄 Manifest.json

ملف يحدد اسم التطبيق، أيقوناته، وألوان الواجهة ليتم تثبيته على الشاشة الرئيسية للجهاز.

⚙️ Service Worker

سكربت يعمل في الخلفية لتخزين الملفات مؤقتاً (Caching) لفتح الموقع بدون اتصال بالإنترنت.

💾 LocalStorage

خاصية لتخزين البيانات دائماً على متصفح المستخدم دون تاريخ انتهاء صراحة.

💻 الأكواد والتطبيق

ربط ملف البيان (Manifest) واستخدام Web Storage

<!-- 1. ربط ملف Manifest داخل <head> -->
<link rel="manifest" href="/manifest.json">
<meta name="theme-color" content="#06b6d4">

<!-- 2. مثال لحفظ جلب قيمة من LocalStorage -->
<script>
  // حفظ اسم المستخدم
  localStorage.setItem("username", "Ahmed");

  // قراءة القيمة
  const user = localStorage.getItem("username");
  console.log(user); // Ahmed
</script>
👁️ المعاينة والتوضيح

الفارق بين أنواع التخزين داخل المتصفح:

🔹 `localStorage`: تخزين دائم للبيانات؛ لا تضيع حتى عند إغلاق المتصفح أو إعادة تشغيل الجهاز (مثل حفظ الثيم الليلي).

🔹 `sessionStorage`: تخزين مؤقت؛ تمحى البيانات فور إغلاق تبويب الصفحة (Session).

🔹 `Cookies`: تخزين صغير الحجم ترسل مع كل طلب للهوست (Server) وغالباً تستخدم للجلسات والتحقق من الهوية.
