🎨 SVG vs Canvas

مقارنة بين SVG و Canvas في HTML5

يوفر HTML5 وسيلتين قويتين للتعامل مع الرسوميات داخل الصفحة مباشرة بدون الاستعانة بملفات صور خارجية:

  • SVG (Scalable Vector Graphics): رسومات متجهة معتمدة على عناصر HTML المتداخلة (مثل <circle> و <rect>). تتميز بأنها لا تفقد جودتها إطلاقاً عند التكبير، ويمكن التحكم بها عبر CSS.
  • Canvas (لوحة الرسم): عنصر يوفر مساحة نقطية (Pixel-based) يتم الرسم والتحريك عليها برمجياً باستخدام JavaScript (مناسبة للألعاب والرسوم البيانية المتقدمة).
<!-- كود رسم دائرة بـ SVG -->
<svg width="100" height="100">
    <circle cx="50" cy="50" r="40" fill="#a855f7" />
</svg>

<!-- كود عنصر Canvas للرسم عبر JavaScript -->
<canvas id="myCanvas" width="200" height="100"></canvas>
⚡ الرسم بـ Canvas

كيف نكود داخل Canvas؟

الوسم <canvas> مجرد حاوية، وتتم عملية الرسم عليها باستخدام سياق الرسم (Rendering Context) عبر السكربتات:

const canvas = document.getElementById('myCanvas');
const ctx = canvas.getContext('2d');

// رسم مستطيل ملون
ctx.fillStyle = '#6366f1';
ctx.fillRect(10, 10, 150, 80);
