⚙️ واجهات HTML5 البرمجية

ما هي واجهات HTML5 المتقدمة (Web APIs)؟

يقدم HTML5 مجموعة من الواجهات التفاعلية الحديثة المدمجة مباشرة بالمتصفح، والتي تجعل تطبيقك يعمل كأنه تطبيق سطح مكتب أو تطبيق هاتف ذكي بدعم كامل للحفظ والتعامل مع أجهزة المستخدم:

💾 LocalStorage

لحفظ البيانات في متصفح المستخدم بصفة دائمة حتى بعد إغلاق المتصفح.

📍 Geolocation API

لتحديد إحداثيات موقع المستخدم الجغرافي (خطوط الطول والعرض) بإذنه.

🖐️ Drag and Drop

خاصية تمكّن المستخدم من سحب العناصر وإسقاطها داخل واجهة المستخدم مباشرة.

💻 الأكواد والتطبيق

أمثلة برمجية لاستخدام APIs

<!-- 1. التخزين المحلي LocalStorage -->
<script>
  localStorage.setItem('username', 'أحمد');
  console.log(localStorage.getItem('username'));
</script>

<!-- 2. جعل العنصر قابلاً للسحب -->
<div draggable="true" id="dragBox">اسحبني!</div>

<!-- 3. جلب موقع المستخدم الجغرافي -->
<script>
  navigator.geolocation.getCurrentPosition((position) => {
    console.log(position.coords.latitude, position.coords.longitude);
  });
</script>
